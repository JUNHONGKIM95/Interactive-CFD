# Flow Lab — interactive 2D CFD

별도 **3D 버전**은 `3D 실행.bat` 또는 `3d/index.html`로 실행합니다. 구·직육면체, XYZ 위치/치수 변경, 3D 입자 및 이동 가능한 속도 단면을 제공합니다. 자세한 내용은 [3D 설명서](3d/README.md)를 참고하세요.

## 실행

`index.html`을 Edge 또는 Chrome에서 더블클릭해 엽니다. 설치, 인터넷 연결, 서버가 필요하지 않습니다. `실행.bat`으로도 열 수 있습니다.

## 조작

- 원형 또는 사각형 장애물을 클릭하고 드래그합니다. 선택 목록과 X/Y 슬라이더로도 이동할 수 있습니다.
- 지름 또는 너비·높이를 조절합니다. 장애물은 최대 12개까지 추가/삭제할 수 있습니다.
- 유입 속도와 점성계수를 바꾸면 Reynolds 수가 갱신됩니다. D는 유동에 수직인 장애물 높이(원은 지름)입니다.
- 속도, 와도, 상대 압력 및 입자·벡터 표시를 선택할 수 있습니다.
- 일시정지 상태에서도 장애물 편집이 가능합니다. 유동 초기화는 현재 장애물과 설정을 유지합니다.
- 계산이 느리면 계산 속도(step/frame)를 낮추세요. 이는 시간 적분 간격을 바꾸지 않고 화면당 계산 횟수만 바꿉니다.

## 수치 모델 및 한계

320 × 160 정규 격자에서 D2Q9 BGK 격자 볼츠만법을 CPU JavaScript로 계산합니다. 격자 단위 dx=dt=ρ₀=1, ν=(τ−0.5)/3, 음속 cₛ=1/√3입니다. 왼쪽 Zou/He 속도 경계, 오른쪽 분포함수 0차 외삽 유출 경계, 상하 벽 및 장애물 halfway bounce-back을 적용합니다. 압력은 p−p₀=(ρ−1)/3, 와도는 ∂v/∂x−∂u/∂y로 표시합니다. 화면 좌표는 y가 아래로 증가하므로 양의 와도는 화면상 시계 방향입니다.

길이는 lu, 시간은 ts로 표시하며 SI 단위와의 변환은 제공하지 않습니다. 모든 색상 범위는 고정이며 범위 밖 값은 색상 끝값으로 포화됩니다. 입자는 속도장을 따라 이동하는 시각화 요소입니다.

장애물 편집은 고체 마스크를 즉시 바꾸고 바뀐 셀을 평형분포로 초기화합니다. **실제로 움직이는 물체의 속도 경계나 유체-구조 연성은 구현하지 않습니다.** 이동 시 발생하는 과도응답은 물리적인 이동체 응답으로 해석하면 안 됩니다. 겹친 장애물은 합쳐진 고체 영역으로 처리합니다.

저마하수·2D 근사에 기반한 정성적 학습 도구입니다. 조밀한 장애물, 좁은 간극, 낮은 점성에서 정확도 또는 안정성이 떨어질 수 있습니다. 비유한 값, 과도한 밀도/속도를 감지하면 유동을 자동 초기화합니다. 이런 경우 점성을 높이거나 유입 속도를 낮추세요. 정량적 설계에는 격자/시간 수렴, 출구 거리, 질량 보존 및 검증 실험을 별도로 검토해야 합니다. 힘·항력·난류 모델은 제공하지 않습니다.

## 개발 확인

Node.js가 있으면 `node test.cjs`로 평형 유동, 장애물, 위치·크기 변경, 매개변수 및 수치 유한성을 확인합니다.
