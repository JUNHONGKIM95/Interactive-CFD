# Flow Lab 3D

## 실행

상위 폴더의 `3D 실행.bat` 또는 이 폴더의 `index.html`을 더블클릭해 최신 Edge/Chrome에서 엽니다. 설치·인터넷·서버가 필요 없습니다. 원본 2D 앱은 그대로 유지됩니다. 계산 코드는 로컬 스크립트로 로드하고 Blob Web Worker에서 실행합니다.

## 조작

- **유입 속도 범위는 0.005–125 u/t**입니다. 넓은 범위를 다루기 위해 로그 슬라이더와 숫자 직접 입력을 제공합니다. 숫자를 입력한 뒤 **입력 속도 적용** 또는 Enter를 누르세요.
- **목표 Re**에 5000을 입력하고 **목표 Re에 맞춰 속도 적용**을 누르면 선택 장애물의 기준 길이 D와 현재 분자 점성으로 U=Re×ν/D를 계산합니다. 기본 D=10, ν=0.025이면 U=12.5 u/t입니다. 장애물이 없으면 버튼은 비활성화됩니다. 계산된 속도가 지원 범위 밖이면 안내합니다.
- 목표 Re는 적용 시점의 값이며 고정 잠금 기능이 아닙니다. 물체 크기, 선택 물체, 점성 변경 후에는 현재 Re가 달라집니다. 필요한 경우 다시 적용하세요. 직접 입력 속도로 Re>5000이 되면 미검증 범위임을 표시합니다.
- 속도/점성 변경 시 시간 단위 변환도 달라질 수 있어 유동을 초기화합니다. 입자 색상과 물리 시간은 계산에 사용한 스케일을 따릅니다.

- **도메인 & 격자**에서 X 길이·Y 높이·Z 깊이와 Δx를 각각 정하고 적용합니다. 적용 전 격자 수 및 대략적인 배열 메모리 사용량을 표시합니다. 실제 브라우저 메모리와 일시적인 재할당 비용은 더 클 수 있습니다.
- 기본 도메인은 **120 × 48 × 48 u**, Δx=**0.75 u**이며 **161 × 65 × 65 = 680,225개** 격자점입니다. 기존 버전은 72 × 32 × 32개, Δx=1이었습니다.
- Δx=0.5이면 같은 도메인에 **241 × 97 × 97 = 2,267,569개** 격자점이 생깁니다. 큰 격자는 CPU 계산이 느려지지만 화면 조작은 별도 스레드로 유지합니다. 격자는 최대 250만 개로 제한합니다.
- 도메인 입력 범위는 X 72–240, Y/Z 30–96 u입니다. 길이는 Δx 배수로 반올림하며 적용될 길이를 미리 표시합니다. 최대 크기와 가장 작은 Δx를 동시에 쓰면 격자 수 제한을 넘으므로 적용할 수 없습니다.
- 해상도 변경 시 장애물의 사용자 단위 치수와 좌표를 유지하고 유동은 초기화합니다. 도메인을 축소해 장애물이 영역을 벗어나면 경계 안쪽으로 위치/크기를 제한합니다. 새로 열면 기본 설정으로 시작합니다.

- 빈 공간을 드래그: 시점 회전. 휠: 확대/축소.
- 구/직육면체를 클릭: 선택. 드래그: 선택한 XY/XZ/YZ 평면에서 이동.
- X·Y·Z 슬라이더: 세 방향 위치 변경. 구는 지름, 직육면체는 너비 X·높이 Y·깊이 Z 변경.
- 시점 버튼: 입체 / XY 정면 / XZ 위 / YZ 측면. 정면 시점 버튼은 드래그 평면도 함께 바꿉니다.
- 장애물은 최대 8개. 겹치면 합쳐진 고체로 계산합니다.
- XY/XZ/YZ 속도 단면을 선택하고 위치를 바꿔 내부 흐름을 관찰합니다.
- 입자 경로와 색은 계산된 3D 속도장을 따릅니다. 초기 입자는 도메인 전체에 배치되며 이후 유입부에서 재생성됩니다.
- 일시정지 중에도 시점·형상·단면 편집 가능. 초기화는 현재 형상과 설정을 유지합니다.
- 느릴 경우 Δx를 늘리거나 도메인을 줄이세요. 계산량을 1로 줄이면 편집 응답 간격이 짧아집니다. 계산량은 update당 시간 스텝 수입니다. 표시 FPS와 실제 step/s는 별개입니다.

## 수치 모델

사용자가 정한 3D 정규 격자에서 D3Q19 격자 볼츠만법을 계산합니다. UI에서는 2차 비평형 응력 정규화와 Smagorinsky SGS(Cs=0.18)를 사용합니다. 비교용 기본 BGK 경로는 솔버에 남겨두었습니다. 세 방향 속도 u,v,w 모두 실제 분포함수의 운동량으로 구합니다.

- 계산 내부에서는 dx=dt=ρ₀=1, cₛ²=1/3, ν_LB=(τ−0.5)/3입니다. 사용자 공간은 임의의 길이 단위 u, 시간 단위 t를 사용하며 SI 단위는 아닙니다.
- Δt=min(Δx², 0.06×Δx/U_user), U_LB=U_user×Δt/Δx, ν_LB=ν_user×Δt/Δx², D_LB=D_user/Δx로 변환합니다. 물체 치수와 입력 Re=U_LB×D_LB/ν_LB는 유지됩니다. 유입 U_LB≤0.06 (유입 Ma≤0.104)로 제한하며, 이는 장애물 주변의 국소 마하수 상한을 보장하지 않습니다. 화면 t는 실제 계산된 Δt의 누적값입니다.
- 비평형 응력 Π의 2차 Hermite 성분을 이용해 충돌 후 분포를 재구성합니다. Smagorinsky 유효 완화시간은 τ_eff=(τ₀+√(τ₀²+18 Cs² √(2 Π:Π)/ρ))/2이며, τ₀=0.5+3ν_LB입니다. 국소 SGS 점성이 더해지므로 화면 Re는 분자 점성으로 정의한 **입력 Re**이지 국소 유효 점성에 대한 Re가 아닙니다.
- +X 방향 유동. 왼쪽은 속도 지정, 오른쪽은 밀도 1 지정. 인접 유체 셀의 비평형 성분을 외삽합니다.
- Y/Z 외벽과 장애물에 stationary halfway bounce-back (no-slip)을 적용합니다.
- Re=Uᵢₙ D/ν. 구는 지름, 직육면체는 Y/Z 중 큰 길이를 D로 사용합니다.
- 속도 색상 범위는 0–2 Uᵢₙ로 고정하며 초과 값은 끝 색상으로 포화됩니다.
- 입자는 삼선형 보간 및 중점법으로 이동합니다. 단면은 매 격자값을 텍스처에 담고 8×8 타일로 그립니다. 렌더링을 위해 수치 격자를 건너뛰지 않습니다. 바닥 선은 방향을 파악하는 보조선이며 모든 계산 격자를 나타내지는 않습니다.
- 화면은 직교 투영의 깊이 정렬 렌더링입니다. 투명한 단면·입자 교차에는 시각적 정렬 오차가 있을 수 있습니다.

## 해석 범위

실시간 관찰을 위한 낮은 해상도의 저마하수 LES 근사입니다. **Re 5000 입력과 유한시간 수치 안정성을 확인했지만, 이 해상도에서 Re 5000 유동의 정량 정확도를 검증한 것은 아닙니다.** 기본 구는 지름에 약 13.3개, Δx=0.5에서도 20개 격자만 있습니다. 미세 와류·경계층을 충분히 해상하지 못하며 SGS 점성과 격자에 따라 후류가 달라질 수 있습니다. 벽 감쇠/벽 모델도 없습니다. SI 치수 변환, 적응 격자, 양력/항력 평가, 유체-구조 연성은 제공하지 않습니다. 실제 설계에는 격자 수렴, 질량 보존, 경계조건 및 기준 문제 검증이 필요합니다.

장애물을 이동하거나 늘리면 고체 마스크가 바뀌고 변경된 셀을 평형 분포로 초기화합니다. 실제 이동체의 속도 경계조건을 구현하지 않았으므로 편집 도중의 과도응답을 물체 이동의 물리적 응답으로 해석하지 마세요. 편집 후 새 형상에 유동이 적응하는 과정을 관찰하는 도구입니다.

좁은 틈·큰 장애물·낮은 점성에서 불안정해질 수 있습니다. 밀도/속도 비정상값을 감지하면 초기화 후 자동 일시정지하고 안내합니다. Re를 낮추거나 격자를 세분화한 뒤 재생하세요. 반복될 경우 형상 배치를 변경하세요. 무한 초기화 반복을 성공한 계산으로 표시하지 않습니다.

## 개발 확인

프로젝트 루트에서 `node 3d/test3d.cjs`로 수치 회귀 검사를, `node 3d/testmesh.cjs`로 세 가지 해상도의 실행, 좌표·치수·Re 보존, 격자 상한을 검사합니다. 이 테스트는 정량적 격자 수렴 검증을 대체하지 않습니다. UI 미리보기에는 `node 3d/preview.cjs`를 실행한 후 출력되는 localhost 주소를 열 수 있습니다. 서버는 이 프로젝트의 정적 파일만 127.0.0.1에 제공합니다.

`node 3d/testhighre.cjs`는 Re/시간 변환, 유입 마하수 제한, Re 5000의 구/직육면체를 각각 64×32×32에서 1,800 스텝, 기본 161×65×65에서 구를 120 스텝 검사합니다. 격자·형상별 모든 장시간 안정성을 보증하지 않습니다.
